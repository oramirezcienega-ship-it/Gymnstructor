# Reglas de Comportamiento del Asistente

- **PROHIBIDO realizar Git Push o Git Commit automático:** El asistente NUNCA debe ejecutar comandos como `git push`, `git commit` o cambios de ramas remotas sin que el usuario lo haya aprobado explícitamente y por escrito en el mensaje inmediatamente anterior.
- **Rama por defecto:** Todo el desarrollo y pruebas locales deben realizarse en la rama `dev`. Queda prohibido subir o mezclar cambios en la rama `main` a menos que se indique explícitamente.
