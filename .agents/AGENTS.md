# Reglas de Comportamiento del Asistente

- **Git Push y Commit automático a `dev`:** Al finalizar y verificar exitosamente cada tarea, el asistente debe realizar automáticamente el `git commit` y `git push` a la rama `dev`.
- **Rama por defecto:** Todo el desarrollo y cambios deben subirse a la rama `dev`. Queda prohibido subir o mezclar cambios en la rama `main` a menos que se indique explícitamente.
